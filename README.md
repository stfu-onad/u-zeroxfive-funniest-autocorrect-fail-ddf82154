# Funniest Autocorrect Fail

Entry for the make.fun bounty
[u-zeroxfive-funniest-autocorrect-fail-ddf82154](https://make.fun/bounty/u-zeroxfive-funniest-autocorrect-fail-ddf82154)

`main.py` (Python 3.13, standard library only) writes one funny
autocorrect fail — one line, 132 characters (gate is 1–199) — to
`/output/entry.txt`.

The fail is **"I texted my landlord 'the sink is leaking' and
autocorrect sent 'the sink is leaving' — now he's charging me for
its farewell party."**

Run it:

```sh
python3 main.py
```

Then read `/output/entry.txt`.
